<objective>
Fix Bug #10: `update_extractor` always fails with `400 Null extractorType`.

Graylog's extractor READ DTO (GET / list responses) names the type field `type`,
but `update-extractor.js` reads `current.extractor_type` — which is `undefined` —
so the key drops out of the serialized PUT body and Graylog's
`CreateExtractorRequest` deserializer rejects the request.

Purpose: Restore `update_extractor` to working order against Graylog 7.x.
Output: One-line source fix + comment correction + a regression test.
</objective>
