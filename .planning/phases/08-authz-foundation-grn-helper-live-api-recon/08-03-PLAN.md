<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP probe script → live Graylog 7.0.6 production | The probe issues a real network call against live UNESCO production infrastructure; the `test` connection is NOT a sandbox |
| captured fixture → Phase 9/10 parser | The fixture becomes the trusted contract for `EntityShareResponse` parsing; a fixture from the wrong source spoofs the API contract |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-06 | Tampering | `capture-authz-prepare-fixture.js` recon probe | mitigate | The probe calls ONLY `POST .../prepare` (`@NoAuditEvent`) with an empty body `{}`; the script asserts its own request path ends in `/prepare` and exits non-zero otherwise. The commit endpoint `POST .../entities/{GRN}` is forbidden this phase — grep-gated absent in Task 1's acceptance criteria. No `dryRun: false` anywhere in Phase 8. |
| T-08-07 | Tampering / Injection | GRN in the request path | mitigate | The entity GRN is built via `buildGrn` (validated type) and `encodeURIComponent`-encoded before path interpolation (colons → `%3A`), so a literal-colon GRN cannot mis-route the JAX-RS router (Pitfall 4). |
| T-08-08 | Spoofing (of API contract) | `prepare-response-7.0.6.json` fixture | mitigate | The fixture MUST be a verbatim capture of the live 7.0.6 `test` instance response, never hand-built from the 7.2 source clone (Pitfall 5 — `synced_entities` may be absent on 7.0.6). A `_provenance` block records instance + version + capture date; the human-verify checkpoint (Task 2) confirms the capture came from a real HTTP 200. The fallback provisional fixture is explicitly marked `provisional: true` and gates Phase 9. |
| T-08-09 | Information Disclosure | sharing a real production stream | accept | The probe READS current grants on an existing stream via an empty-body `/prepare`; it grants nothing. Reading who-can-see-what on one stream is `@NoAuditEvent` and low risk; the probe never writes a grant and never targets `builtin-team:everyone`. |
| T-08-SC | Tampering | npm/pip/cargo installs | mitigate | Zero new packages — the probe uses the installed `axios` indirectly via `makeClient` and Node built-ins `node:fs`/`node:path`/`node:url` (08-RESEARCH §"Package Legitimacy Audit" — not applicable). Any `npm install` proposal violates the zero-new-dependency constraint. |
</threat_model>
