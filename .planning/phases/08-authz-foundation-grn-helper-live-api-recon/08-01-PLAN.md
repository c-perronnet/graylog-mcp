<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent → MCP tool input | A future authz tool will pass a GRN type / capability string; this plan builds the client-side validators that gate that input before any Graylog call |
| MCP code → Graylog request path | A malformed GRN interpolated into a `@PathParam` could mis-route the JAX-RS router; `buildGrn` constrains the type token at construction time |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Tampering / Injection | `buildGrn` / `parseGrn` (`grn-helpers.js`) | mitigate | `buildGrn` validates the type token against the closed `GRN_TYPES` set and rejects anything else with an explicit error; `parseGrn` enforces exactly-6-token structure. A malformed or unknown-type GRN cannot be constructed client-side. |
| T-08-02 | Elevation of Privilege | `Capability` enum (`schemas.js`) | mitigate | Enum pinned to exactly `view`/`manage`/`own`; `read`/`write`/`edit`/`admin` synonyms are rejected, so capability privilege confusion (e.g. silently treating `admin` as `own`) cannot occur. Downstream tools default to least privilege (`view`). |
| T-08-03 | Spoofing (of API contract) | `GRN_TYPES` set | accept | `GRN_TYPES` is the restricted 6-type milestone set, not the full 14-type 7.2 registry. Accepted as low risk: the 6 types are all verified in scope; a type live 7.0.6 rejects can never be built because it is not in the set. |
| T-08-SC | Tampering | npm/pip/cargo installs | mitigate | Phase 8 installs zero external packages (08-RESEARCH §"Package Legitimacy Audit" — not applicable). If any task proposes `npm install`, it violates the CLAUDE.md zero-new-dependency constraint and must be rejected. |
</threat_model>
