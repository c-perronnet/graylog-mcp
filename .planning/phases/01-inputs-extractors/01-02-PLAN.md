Encrypted-field merge contract (RESEARCH.md §"Encrypted-Field Merge" + CITED EncryptedInputConfigs.java:44-53):
- Wire shapes that Graylog's EncryptedInputConfigs.merge accepts in a PUT body's configuration field:
  - `{ <encField>: "newSecret" }` (plain string) → Graylog encrypts as new value
  - `{ <encField>: { keep_value: true } }` → Graylog keeps existing value
  - `{ <encField>: { delete_value: true } }` → Graylog clears the value
  - OMIT the field entirely → Graylog's merge logic preserves original (this is our default for unspecified encrypted fields)
  - NEVER send `{ <encField>: { is_set: true } }` — the GET response shape; in PUT context = undefined behavior

D-03 / ROADMAP success criterion 2 — wire-body shape for update_input:
- Graylog's PUT /api/system/inputs/{id} requires a body with top-level `type`, `title`, `global` (and optional `node`) — these are the "envelope" fields. The wrapper builds these by merging args.changes top-level fields over current top-level fields (acceptable: agent rarely retypes the immutable `type`; we always include it).
- The `configuration` object inside the body is the diff zone. The wrapper builds it STRICTLY from `args.changes.configuration` — never copies unchanged non-encrypted entries from current.configuration. Graylog's deserializer accepts a partial configuration on PUT; unspecified fields are preserved server-side per EncryptedInputConfigs.merge semantics. This is the "only the changed field" promise from ROADMAP success criterion 2.

    ```js
    // Encrypted-field redaction helpers (D-04 for create, D-03 for update).
    // - redactForPreview replaces encrypted values with a placeholder string for dry-run output.
    // - encodeEncryptedForWire wraps an explicit new value in { set_value } so Graylog's
    //   EncryptedInputConfigs.merge treats it as a fresh encryption target.

    export const REDACTION_PLACEHOLDER = "<redacted>";

    /**
     * Replace encrypted-field values in a configuration object with REDACTION_PLACEHOLDER.
     * Pure: returns a new object; does not mutate the input.
     * @param {Record<string, unknown>} configuration
     * @param {Set<string>} encryptedFields
     */
    export function redactForPreview(configuration, encryptedFields) {
        if (!configuration || typeof configuration !== "object") return configuration;
        const out = { ...configuration };
        for (const field of encryptedFields) {
            if (field in out) out[field] = REDACTION_PLACEHOLDER;
        }
        return out;
    }

    /**
     * Wrap explicit encrypted-field values in { set_value: <value> } for the wire body.
     * Plain strings → { set_value: string }. Already-shaped placeholders ({ keep_value }, { delete_value })
     * are passed through unchanged.
     */
    export function encodeEncryptedForWire(configuration, encryptedFields) {
        if (!configuration || typeof configuration !== "object") return configuration;
        const out = { ...configuration };
        for (const field of encryptedFields) {
            if (!(field in out)) continue;
            const v = out[field];
            if (v && typeof v === "object" && ("keep_value" in v || "delete_value" in v || "set_value" in v)) {
                // Already a Graylog placeholder shape — pass through.
                continue;
            }
            if (typeof v === "string") {
                out[field] = { set_value: v };
            }
            // Other types (numbers, booleans for encrypted fields are not expected; leave as-is)
        }
        return out;
    }
    ```

    Step 4 — Create src/tools/inputs/update-input.js (INPUT-05 — C3 mitigation + D-03 STRICT NO-ECHO; BLOCKER #2 fix). Key change from the prior plan iteration: the wire `configuration` is built STRICTLY from `args.changes.configuration` — no copy-from-current loop. Top-level required envelope fields (type, title, global, node) are merged from current state only when the agent did not pass them.

    ```js
    import { defineMutatingHandler } from "../_shared/handler.js";
    import { UpdateInputSchema } from "./schemas.js";
    import { getCachedTypeCatalogue, getEncryptedFieldNamesForType } from "./type-catalogue.js";
    import { redactForPreview, encodeEncryptedForWire } from "./redact.js";
    import { resolveConnection } from "../_shared/connection.js";
    import { makeClient } from "../../graylog/client.js";
    import { toIdBody } from "../../graylog/normalize.js";

    export const handleUpdateInput = defineMutatingHandler({
        name: "update_input",
        schema: UpdateInputSchema,
        async build(args) {
            const seamArgs = args._testConnection ? { ...args, _testConnection: args._testConnection } : args;
            const { conn, name: connectionName } = resolveConnection(seamArgs);
            const client = makeClient(conn);
            // 1. Pre-flight: fetch current input state (needed for top-level envelope fields like `type`)
            const current = await client.request("GET", `/api/system/inputs/${args.inputId}`, null);
            // 2. Fetch catalogue to learn encrypted fields for this input type (still needed for the
            //    encrypted-field { set_value } wire encoding + the preview redaction)
            const catalogue = await getCachedTypeCatalogue(connectionName, conn);
            const encryptedFields = getEncryptedFieldNamesForType(catalogue, current.type);

            // 3. D-03 strict no-echo: the wire `configuration` is built ONLY from
            //    `args.changes.configuration`. We do NOT iterate `current.configuration`
            //    and copy unchanged non-encrypted entries — that violates ROADMAP success
            //    criterion 2 ("only the changed field") and is the bug the prior plan
            //    iteration introduced. Graylog's PUT deserializer accepts a partial
            //    configuration and preserves unspecified fields server-side via
            //    EncryptedInputConfigs.merge semantics.
            //
            //    When the agent passes `changes.configuration = {}` (no-op), the wire
            //    configuration is an empty object — zero echoed fields, neither
            //    encrypted nor unencrypted. The encrypted-field set still matters
            //    here for the encode/redact step below.
            const agentConfig = args.changes.configuration ?? null;  // null sentinel: agent did NOT touch configuration at all

            // 4. Top-level envelope fields. PUT requires `type`, `title`, `global` per Graylog's
            //    InputCreateRequest deserializer. Use current state when agent did not pass.
            //    `node` is optional — only include if either current or changes specified one.
            const wireBody = {
                type: current.type,  // immutable on update; never from agent input
                title: args.changes.title ?? current.title,
                global: args.changes.global ?? current.global,
                ...(args.changes.node !== undefined || current.node !== undefined
                    ? { node: args.changes.node ?? current.node }
                    : {}),
                // Configuration block: include only if agent passed `changes.configuration` (even {}).
                // If agent did not touch configuration at all (`null` sentinel above), omit the key
                // entirely from the wire body — matches "only the changed field" most strictly.
                ...(agentConfig !== null
                    ? { configuration: encodeEncryptedForWire(agentConfig, encryptedFields) }
                    : {}),
            };
            const previewBody = {
                ...wireBody,
                ...(agentConfig !== null
                    ? { configuration: redactForPreview(agentConfig, encryptedFields) }
                    : {}),
            };
            return {
                method: "PUT",
                path: `/api/system/inputs/${args.inputId}`,
                body: previewBody,
                postApplyEstimate: { id: args.inputId },
                normalize: (raw) => toIdBody(raw, { idFields: ["id"] }),
                _applyBody: wireBody,
            };
        },
        apply: (client, req) => client.request(req.method, req.path, req._applyBody ?? req.body),
        summarize: (args) => `Update input ${args.inputId} (${Object.keys(args.changes).length} change(s))`,
    });
    ```
