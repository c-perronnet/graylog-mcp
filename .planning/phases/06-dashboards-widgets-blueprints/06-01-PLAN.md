```javascript
export function validateWidgetPositionIntegrity(widgets, widgetPositions) {
  // widgets: Array<{id: string, ...}>
  // widgetPositions: Record<string, {col, row, height, width}>
  // Bidirectional strict-equality check (RESEARCH Pitfall 4 — server only checks ⊇).
  // Throws Error with .reason = "widget_position_integrity_violation" + .isClientSide = true.
  const widgetIds = new Set(widgets.map(w => w.id));
  const positionIds = new Set(Object.keys(widgetPositions ?? {}));
  const widgetsWithoutPositions = [...widgetIds].filter(id => !positionIds.has(id));
  const positionsWithoutWidgets = [...positionIds].filter(id => !widgetIds.has(id));
  if (widgetsWithoutPositions.length || positionsWithoutWidgets.length) {
    const err = new Error(
      `Widget/position integrity violation: ` +
      `widgets missing positions [${widgetsWithoutPositions.join(", ")}]; ` +
      `positions missing widgets [${positionsWithoutWidgets.join(", ")}]`
    );
    err.reason = "widget_position_integrity_violation";
    err.isClientSide = true;
    throw err;
  }
}
```

**Step B — `src/tools/_shared/blueprint-chain.js`** (executeChain + substitutePlaceholders). Implementation per RESEARCH Pattern 3:

Exports two functions:
1. `export async function executeChain(client, chain)` — walks a chain array `[{step, tool, request: {method, path, body}, dependsOn?, postApplyEstimate?}, ...]`. For each step:
   - If `dependsOn` present: find prior step by step number from `dependsOn.from` (e.g. parse `"step1.response.id"` → step 1, field path `response.id`); look up prior's response; if absent return `{isError: true, reason: "blueprint_chain_unresolved_dependency", content: [{type: "text", text: JSON.stringify({transcript, missing_dependency: step.dependsOn})}]}`.
   - Substitute placeholders in `step.request.body` AND `step.request.path` using `substitutePlaceholders`.
   - `await client.request(method, path, body)`; on success push `{step, tool, request, response}` to transcript.
   - On throw push `{step, tool, request, error: err.message}` and return `{isError: true, reason: "blueprint_chain_partial_failure", content: [{type: "text", text: JSON.stringify({transcript, failed_at_step: step.step, succeeded_steps: transcript.filter(t => !t.error).map(t => t.step)})}]}`.
   - On full success return `{applied: true, transcript}`.

2. `export function substitutePlaceholders(obj, dependsOn, replacement)` — recursive walker:
   - If `obj` is a string matching `${SERVER_ASSIGNED_SENTINEL}step{N}` where N matches the step in dependsOn: return replacement.
   - If array: map recursively.
   - If object (non-null): map entries recursively.
   - Otherwise return obj unchanged.

`dependsOn` may be either a single object `{from: "step1.response.id", as: "streamId"}` or an array of such objects (e.g. BLUE-01 step 4 has both stream + pipeline deps). Handle both shapes.

Import `SERVER_ASSIGNED_SENTINEL` from `./dry-run.js`.
