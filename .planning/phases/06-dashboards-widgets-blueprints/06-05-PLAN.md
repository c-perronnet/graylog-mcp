## Stream-id KEY note (CRITICAL for BLUE-01)

`POST /api/streams` returns `{stream_id: "<uuid>"}` — the response key is `stream_id`, NOT `id`. Phase 3 establishes this. BLUE-01 step 4 + step 5 + step 6 all reference step 1's response via `step1.response.stream_id`, NOT `step1.response.id`. The `executeChain` substitutePlaceholders walker (Plan 01) must handle dot-notation paths in `dependsOn.from`. Plan 01 Task 2 already specifies the walker resolves `step{N}.response.<field>` — if needed, amend Plan 01's walker to traverse the field path explicitly.

**Defensive resolution**: BLUE-01 step 1 apply-path post-processing normalizes the response to expose BOTH `id` AND `stream_id` to downstream steps. This is a one-line shim in BLUE-01's apply override OR a small enhancement to substitutePlaceholders. Use the simpler path: assemble the chain so the placeholder for step 1's stream id is `${SERVER_ASSIGNED_SENTINEL}step1.stream_id` and the substitutePlaceholders walker resolves `stream_id` from the response object.

**Actual implementation pattern**: Plan 01's executeChain expects placeholders matching `${SENTINEL}step{N}` (singular form). To carry a different field name from step 1, the blueprint's apply can pre-process: after each step, normalize the response so `response.id = response.stream_id ?? response.id`. This keeps the placeholder grammar simple AND honors Graylog's wire shape.

**Plan 05 decision**: assemble the chain such that step 1's response is normalized to have `response.id = streamId`. Easiest path: BLUE-01 supplies its OWN apply function that calls services directly (not executeChain) but accumulates a transcript in the same shape. **Better**: keep executeChain, and let BLUE-01's apply post-process step 1's response BEFORE handing it to executeChain.

**Cleanest pattern (final)**: enhance substitutePlaceholders in Plan 01 (already specified to handle the dotted-path `step1.response.id`) to ALSO handle `step1.response.stream_id` by parsing the path after `response.`. This is a 5-line walker enhancement. **Defer to Plan 01's Task 2 if not already covered**; if Plan 01 implements only `.id` resolution, Plan 05 task 1 SHOULD add a Plan 01 amendment in its files_modified.

**Pragmatic resolution adopted in this plan**: BLUE-01's `apply` overrides the chain walker to use a custom resolver that knows how to read `stream_id` from step 1's response. Implementation detail captured in Task 1.

**Step B — `src/tools/blueprints/setup-app-monitoring-stack.js`** per RESEARCH §"BLUE-01 Chain Anatomy":

```javascript
import { defineMutatingHandler } from "../_shared/handler.js";
import { SetupAppMonitoringStackSchema } from "./schemas.js";
import { createStream } from "../../services/streams.js";
import { createPipeline, createRule, connectToStream } from "../../services/pipelines.js";
import { createSearch, createDashboard, buildSearchDTO, buildViewDTO } from "../../services/dashboards.js";
import { createEventDefinition } from "../../services/events.js";
import { WIDGET_TEMPLATES } from "../../widget-templates/index.js";
import { emitRule } from "../../pipeline-dsl/emit.js";
import { executeChain, substitutePlaceholders } from "../_shared/blueprint-chain.js";
import { SERVER_ASSIGNED_SENTINEL } from "../_shared/dry-run.js";
import { randomUUID } from "node:crypto";

const QUERY_ID = "q-1";

export const handleSetupAppMonitoringStack = defineMutatingHandler({
  name: "setup_app_monitoring_stack",
  schema: SetupAppMonitoringStackSchema,
  async build(args) {
    const dropDebugRuleTitle = `${args.app_name}_drop_debug`;
    const pipelineTitle = `${args.app_name}_pipeline`;
    const dashboardTitle = `${args.app_name} health`;
    const eventDefTitle = `${args.app_name} error rate`;

    // ---- Step 1: createStream ----
    const streamBody = {
      entity: {
        title: `${args.app_name} stream`,
        description: `Auto-generated by setup_app_monitoring_stack for ${args.app_name}`,
        rules: [{
          type: 2,  // Phase 3 numeric rule type for "regex" (verify against Phase 3 D-11 mapping)
          field: "source",
          value: args.source_pattern,
          inverted: false,
          description: `source matches ${args.source_pattern}`,
        }],
        content_pack: null,
        matching_type: "AND",
        remove_matches_from_default_stream: false,
        index_set_id: args.indexSetId,
      },
      share_request: null,
    };

    // ---- Step 2: createRule (drop debug) ----
    const dropDebugSource = emitRule({
      name: dropDebugRuleTitle,
      when: {
        type: "comparison",
        left: {type: "field_ref", source: "message", field: "level"},
        op: ">",
        right: {type: "literal", value: 7},  // syslog: drop level > 7 (debug+)
      },
      then: [{type: "function_call_statement", name: "drop_message", args: {positional: []}}],
    });

    // ---- Step 3: createPipeline ----
    const pipelineSource = [
      `pipeline "${pipelineTitle}"`,
      `stage 0 match either`,
      `    rule "${dropDebugRuleTitle}"`,
      `end`,
    ].join("\n");

    // ---- Step 5: buildDashboard ----
    // Generate widget triplets using seeded-stable IDs (in tests, randomUUID is mocked).
    const streamIdPlaceholder = `${SERVER_ASSIGNED_SENTINEL}step1.stream_id`;
    const triplets = args.defaultDashboardWidgets.map((templateName) => {
      const builder = WIDGET_TEMPLATES[templateName];
      // Build with the placeholder; substitutePlaceholders will swap at apply time.
      return builder({streamIds: [streamIdPlaceholder]});
    });
    const searchDTO = buildSearchDTO({
      queryId: QUERY_ID,
      widgets: triplets.filter(t => t.searchType !== null),
      timerange: {type: "relative", from: 900},
      query: "",
      streamIds: [streamIdPlaceholder],
    });
    const viewDTO = buildViewDTO({
      title: dashboardTitle,
      description: `Auto-generated by setup_app_monitoring_stack`,
      summary: `Error rate + top sources + level distribution + recent events for ${args.app_name}`,
      searchId: `${SERVER_ASSIGNED_SENTINEL}step5a`,  // populated at apply time
      queryId: QUERY_ID,
      widgets: triplets,
    });

    // ---- Step 6: createEventDefinition ----
    const eventDefBody = {
      title: eventDefTitle,
      description: `Auto-generated error-rate alert for ${args.app_name}`,
      priority: 2,
      alert: true,
      config: {
        type: "aggregation-v1",
        query: "level:>=4",
        streams: [streamIdPlaceholder],
        group_by: [],
        series: [{id: "count-1", function: "count", field: null}],
        conditions: {expression: {expr: ">", left: {expr: "number-ref", ref: "count-1"}, right: {expr: "number", value: args.errorRateThreshold}}},
        search_within_ms: 5 * 60 * 1000,
        execute_every_ms: 5 * 60 * 1000,
      },
      key_spec: [],
      notifications: [],
      notification_settings: {grace_period_ms: 60 * 1000, backlog_size: 50},
    };

    // ---- Assemble chain ----
    // Step 5 is conceptually ONE blueprint step but emits 2 HTTP round-trips. We model this as
    // two chain entries (step 5a + step 5b) so executeChain can walk them sequentially.
    const chain = [
      {
        step: 1,
        tool: "create_stream",
        request: {method: "POST", path: "/api/streams", body: streamBody},
        postApplyEstimate: {id: SERVER_ASSIGNED_SENTINEL},
      },
      {
        step: 2,
        tool: "create_pipeline_rule",
        request: {
          method: "POST",
          path: "/api/system/pipelines/rule",
          body: {title: dropDebugRuleTitle, description: "Drop debug-level messages", source: dropDebugSource},
        },
        postApplyEstimate: {id: SERVER_ASSIGNED_SENTINEL},
      },
      {
        step: 3,
        tool: "create_pipeline",
        request: {
          method: "POST",
          path: "/api/system/pipelines/pipeline",
          body: {title: pipelineTitle, description: `Pipeline for ${args.app_name}`, source: pipelineSource},
        },
        postApplyEstimate: {id: SERVER_ASSIGNED_SENTINEL},
      },
      {
        step: 4,
        tool: "connect_pipelines_to_stream",
        request: {
          method: "POST",
          path: "/api/system/pipelines/connections/to_stream",
          body: {stream_id: `${SERVER_ASSIGNED_SENTINEL}step1.stream_id`, pipeline_ids: [`${SERVER_ASSIGNED_SENTINEL}step3`]},
        },
        // Array-shape dependsOn (Plan 01 Task 2 test 4 pins executeChain handles this).
        dependsOn: [
          {from: "step1.response.stream_id", as: "stream_id"},
          {from: "step3.response.id", as: "pipeline_ids[0]"},
        ],
      },
      {
        step: 5,
        tool: "create_dashboard",
        request: {
          // Composite step — surface as one chain entry, but apply walks the inner Search+View pair.
          method: "POST",
          path: "/api/views (internal Search+View chain)",
          body: {
            chain: [
              {step: "5a", method: "POST", path: "/api/views/search", body: searchDTO},
              {step: "5b", method: "POST", path: "/api/views", body: {entity: viewDTO, share_request: null}},
            ],
          },
        },
        dependsOn: {from: "step1.response.stream_id", as: "widgets[].streamIds[0]"},
        postApplyEstimate: {id: SERVER_ASSIGNED_SENTINEL},
      },
      {
        step: 6,
        tool: "create_event_definition",
        request: {
          method: "POST",
          path: "/api/events/definitions?schedule=false",
          body: eventDefBody,
        },
        dependsOn: {from: "step1.response.stream_id", as: "config.streams[0]"},
        postApplyEstimate: {id: SERVER_ASSIGNED_SENTINEL},
      },
    ];

    return {
      chain,
      method: "POST",
      path: "/api/streams",  // primary preview = step 1
      body: streamBody,
      postApplyEstimate: {id: SERVER_ASSIGNED_SENTINEL},
    };
  },
  async apply(client, req) {
    // BLUE-01's apply is a custom chain walker that handles:
    //   (a) step 1's response { stream_id: "..." } (Phase 3 wire shape, NOT { id: "..." })
    //   (b) step 5's nested Search+View internal chain (2 HTTP per step 5)
    //   (c) substitution of step1.response.stream_id into steps 4, 5, 6
    const transcript = [];
    for (const step of req.chain) {
      let body = step.request.body;
      let path = step.request.path;

      // Substitute placeholders from prior transcript.
      const deps = Array.isArray(step.dependsOn) ? step.dependsOn : (step.dependsOn ? [step.dependsOn] : []);
      for (const dep of deps) {
        const match = dep.from.match(/^step(\d+)\.response\.(.+)$/);
        if (!match) continue;
        const priorStep = transcript.find(t => t.step === parseInt(match[1], 10));
        if (!priorStep || !priorStep.response) {
          return {
            isError: true,
            reason: "blueprint_chain_unresolved_dependency",
            content: [{type: "text", text: JSON.stringify({transcript, missing_dependency: dep, failed_at_step: step.step})}],
          };
        }
        const replacement = priorStep.response[match[2]];
        if (replacement === undefined) {
          return {
            isError: true,
            reason: "blueprint_chain_unresolved_field",
            content: [{type: "text", text: JSON.stringify({transcript, missing_field: match[2], step: step.step})}],
          };
        }
        body = substitutePlaceholders(body, dep, replacement);
        path = path.replaceAll(`__SERVER_ASSIGNED__step${match[1]}.${match[2]}`, replacement);
      }

      try {
        let response;
        // Step 5 is a composite: walk the inner Search+View pair.
        if (step.tool === "create_dashboard" && body?.chain) {
          // body.chain has 2 entries; walk them.
          const searchResponse = await client.request(body.chain[0].method, body.chain[0].path, body.chain[0].body);
          const viewBody = JSON.parse(JSON.stringify(body.chain[1].body).replaceAll("__SERVER_ASSIGNED__step5a", searchResponse.id));
          const viewResponse = await client.request(body.chain[1].method, body.chain[1].path, viewBody);
          response = viewResponse;
        } else {
          response = await client.request(step.request.method, path, body);
        }
        transcript.push({step: step.step, tool: step.tool, request: {method: step.request.method, path, body}, response});
      } catch (err) {
        transcript.push({step: step.step, tool: step.tool, request: {method: step.request.method, path, body}, error: err.message ?? String(err)});
        return {
          isError: true,
          reason: "blueprint_chain_partial_failure",
          content: [{
            type: "text",
            text: JSON.stringify({
              transcript,
              failed_at_step: step.step,
              succeeded_steps: transcript.filter(t => !t.error).map(t => t.step),
            }),
          }],
        };
      }
    }
    // Return the dashboard id as the primary result (the agent's mental model is "set up monitoring → got dashboard URL"):
    const dashboardStep = transcript.find(t => t.step === 5);
    return {id: dashboardStep.response.id, body: {transcript}};
  },
  summarize: (args) => `Set up app monitoring stack for ${args.app_name} (stream + pipeline + dashboard + alert; 6-step chain)`,
});
```

import { defineMutatingHandler } from "../_shared/handler.js";
import { SetupErrorAlertingSchema } from "./schemas.js";

export const handleSetupErrorAlerting = defineMutatingHandler({
  name: "setup_error_alerting",
  schema: SetupErrorAlertingSchema,
  async build(args) {
    const title = args.title ?? `Error alert for stream ${args.streamId}`;
    const searchWithinMs = args.searchWithinMinutes * 60 * 1000;
    const eventDefBody = {
      title,
      description: `Auto-generated error-rate alert (>= ${args.errorRateThreshold} errors / ${args.searchWithinMinutes} min)`,
      priority: 2,
      alert: true,
      config: {
        type: "aggregation-v1",
        query: "level:>=4",
        streams: [args.streamId],
        group_by: [],
        series: [{id: "count-1", function: "count", field: null}],
        conditions: {expression: {expr: ">", left: {expr: "number-ref", ref: "count-1"}, right: {expr: "number", value: args.errorRateThreshold}}},
        search_within_ms: searchWithinMs,
        execute_every_ms: searchWithinMs,
      },
      key_spec: [],
      notifications: [{notification_id: args.notificationId, notification_parameters: null}],
      notification_settings: {grace_period_ms: 60 * 1000, backlog_size: 50},
    };

    const chain = [{
      step: 1,
      tool: "create_event_definition",
      request: {
        method: "POST",
        path: "/api/events/definitions?schedule=false",
        body: eventDefBody,
      },
      postApplyEstimate: {id: SERVER_ASSIGNED_SENTINEL},
    }];

    return {
      chain,
      method: "POST",
      path: "/api/events/definitions?schedule=false",
      body: eventDefBody,
      postApplyEstimate: {id: SERVER_ASSIGNED_SENTINEL},
    };
  },
  async apply(client, req) {
    const result = await executeChain(client, req.chain);
    if (result.isError) return result;
    return result.transcript[0].response;
  },
  summarize: (args) => `Set up error alerting on stream ${args.streamId} via notification ${args.notificationId}`,
});

import { defineMutatingHandler } from "../_shared/handler.js";
import { CreateAppHealthDashboardSchema } from "./schemas.js";

export const handleCreateAppHealthDashboard = defineMutatingHandler({
  name: "create_app_health_dashboard",
  schema: CreateAppHealthDashboardSchema,

    const title = args.title ?? `Health dashboard (stream ${args.streamId})`;

      return builder({streamIds: [args.streamId]});

      queryId: QUERY_ID,
      widgets: triplets.filter(t => t.searchType !== null),
      timerange: {type: "relative", from: 900},
      query: "",
      streamIds: [args.streamId],
    });
    const viewDTO = buildViewDTO({
      title,
      description: `Auto-generated health dashboard for stream ${args.streamId}`,
      summary: `4 pre-wired widgets`,
      searchId: `${SERVER_ASSIGNED_SENTINEL}step1`,
      queryId: QUERY_ID,
      widgets: triplets,
    });

    const chain = [
      {
        step: 1,
        tool: "create_search",
        request: {method: "POST", path: "/api/views/search", body: searchDTO},
        postApplyEstimate: {id: SERVER_ASSIGNED_SENTINEL},
      },
      {
        step: 2,
        tool: "create_view",
        request: {method: "POST", path: "/api/views", body: {entity: viewDTO, share_request: null}},
        dependsOn: {from: "step1.response.id", as: "searchId"},
        postApplyEstimate: {id: SERVER_ASSIGNED_SENTINEL},
      },
    ];

    return {
      chain,
      method: "POST",
      path: "/api/views",
      body: {entity: viewDTO, share_request: null},
      postApplyEstimate: {id: SERVER_ASSIGNED_SENTINEL},
    };
  },

    // Reuse the same chain walker shape as create_dashboard (Plan 02). For consistency

    if (result.isError) return result;
    return result.transcript[result.transcript.length - 1].response;
  },
  summarize: (args) => `Create health dashboard for stream ${args.streamId} (4 default widgets via internal Search+View chain)`,
});
