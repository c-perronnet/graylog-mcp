# /api/streams Deprecation — Migration Plan

**Created:** 2026-05-16 (Phase 7 — milestone close)
**Status:** Documented, NOT migrated. Migration is a follow-up milestone.

## Background

Graylog 7.2's `StreamResource.java` marks `GET /api/streams` as `@Deprecated`
(line 297, per `source-code/graylog2-server/.../StreamResource.java`). The
non-deprecated replacement is `GET /api/streams/paginated`. The bare
endpoint still works in 7.2 but may be removed in a future major release.

## Affected Code

| Caller | File:Line | Path |
|--------|-----------|------|
| `fetchStreams()` | `src/query.js:~85` | `GET /api/streams` |
| (none other; the new Phase 3 list_streams already hits /api/streams/paginated) | - | - |

## v7.2 Response Shape Diff

| Endpoint | Response | Pagination |
|----------|----------|------------|
| `GET /api/streams` (deprecated) | `{ total: number, streams: Stream[] }` | None — returns ALL streams |
| `GET /api/streams/paginated` | `{ total, page, per_page, count, elements: Stream[] }` | `?page=N&per_page=M` |

Key differences:
- Field renamed: `streams` → `elements`
- Pagination metadata added: `page, per_page, count`
- Default `per_page` is server-side (50 on 7.2); deprecated endpoint had no cap

## Migration Steps (Future Milestone)

1. Update `fetchStreams()` in src/query.js to hit `/api/streams/paginated`
   with a generous `per_page` (200 — matches MAX_LIMIT in _shared/list.js)
   and walk pages until `count === per_page` becomes false.
2. Normalize the envelope: rename `elements` → `streams` at the boundary so
   downstream callers (search_messages_graylog's streamIds resolution)
   continue to receive the same shape.
3. Add a smoke test mirroring the HARD-03 fixture-based pattern at
   test/fixtures/v7-read-tool-smoke/streams-paginated.json.
4. Drop the deprecated endpoint from any other read paths (audit complete:
   only fetchStreams uses it as of Phase 7 milestone close).

## Effort Estimate

- ~30 min: code change + page-walk loop
- ~30 min: fixture + smoke test update
- ~15 min: regression run + commit
- Total: ~75 min single-plan effort in a future milestone

## Why Not This Milestone

PROJECT.md scope explicitly excludes "backward-compat refactors of existing
v2.3 read tools" — HARD-03's job is to verify-against-v7, NOT refactor.
The deprecation is documented; the migration is owed to v2.4 or whenever
the next milestone wants to close this debt.

## Source

- Graylog source-code/graylog2-server/.../StreamResource.java:297
- PITFALLS.md backward-compat section row 1
